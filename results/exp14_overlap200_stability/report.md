# exp14 overlap200 step-3 재현성 (n=3, 충실 재구현)

이 보고서는 overlap200 아이디어의 step-3(LLM이 GraphRAG 커뮤니티+엔티티를 받아
학습용 방을 설계하는 단계)에 대한 충실 재구현이다. 팀원의 최종 코드와 동일 동작을
보장하지 않으며, 측정 대상은 "접근 방식"의 재현성이다 (LLM이 같은 입력에 여러 번
돌렸을 때 방 구조를 얼마나 동일하게 만들어내는가). 하니스 코드는 공유 가능.

## 입력 고정

- 스냅샷: `results/snapshots/repro_run3` (코퍼스: exp10, TOC 실험과 동일)
- 엔티티: 357개, 커뮤니티(level 0): 40개, community report(level 0): 40개
- level-0 커뮤니티에 안 묶인 엔티티: 31개 (LLM에 "no community" 목록으로 같이 전달)
- 3런 모두 같은 frozen 입력 (`frozen_input.json`)을 사용. 추출 변동은 분리됨.
- ※ overlap200 원래의 1200/overlap200 청킹 변경은 이번 실험 범위 밖.

## 재구현 명세

- 모델: `gpt-4.1-mini` (문서의 "GPT-5.4 mini"는 표준 모델 명과 불일치라 mini로 핀)
- temperature=0, JSON mode, 한 번 호출 = 한 런
- 방 개수: 가이드 "약 6개", LLM이 자율 결정 (±2 허용 명시)
- visibility 4단계: core / supporting / search_only / background
- 게이트: "핵심을 강하게 지지하지 않는 보조성은 supporting 대신 search_only로
  내려라"를 프롬프트 규칙으로 포함
- 모든 엔티티는 정확히 한 방에 + visibility 1개. 누락·중복 금지 명시.

코드: `build_input.py` → `run_design.py --n 3` → `analyze.py`.

## 매칭 + 일치도 (LLM 없는 결정적 평가)

런 간 방 번호가 다를 수 있어 멤버십 자카드로 greedy 매칭한 뒤 페어 통계를 낸다.
런3에서 누락된 엔티티는 "어디에도 안 들어감"이므로 자카드는 양쪽 모두 할당된
엔티티에서만 계산된다. 페어별 비교는 그 쌍에서 양쪽 다 배정된 엔티티만 본다.

| 페어 | 평균 매칭 자카드 | 최소 자카드 | 미매칭 방 | 방 이동 엔티티 | visibility 이동 |
|---|---:|---:|---:|---:|---:|
| run1-run2 | 0.7902 | 0.5000 | 0 | 25 | 40 |
| run1-run3 | 0.5291 | 0.1558 | 0 | 90 | 66 |
| run2-run3 | 0.5148 | 0.1579 | 0 | 100 | 42 |
| 평균 | **0.6114** | **min=0.1558** | 0 | 71.7 | 49.3 |

페어별 7개 방 매칭 디테일은 `agreement.json` 참고.

- run1-run2는 7개 중 5개가 자카드 ≥ 0.78, 최저 0.50
- run1-run3와 run2-run3은 1개 방(둘 다 마지막 "사회/사상" 카테고리)이
  자카드 0.16 부근으로 강하게 흔들림 (run3에서 size 60으로 부풀음)

방 단위로 매칭은 다 됨 (unmatched 0). 즉 "전혀 못 만나는 방"은 없고, 라벨 흐름이
유지되며 멤버십이 일부 셔플되는 모양.

## 앵커 안정성

`results/exp10_room_gen/anchors_korean_history.json`의 `should_show` 14개 앵커
기준:

- **14/14가 3런 모두에서 non-background로 노출** (background로 떨어진 앵커 없음)
- **이성계: 3런 모두 "조선 건국" 방에 `core` visibility**
  - run1: "조선 건국과 초기 왕권 강화" / core
  - run2: "조선 건국과 초기 정치 체계" / core
  - run3: "조선 건국과 초기 중앙집권 체계" / core

핵심 학습 대상 14개와 도메인 메인 앵커(이성계)는 흔들리지 않음.

## 판정

**부분 재현 (안정한 골격 + 흔들리는 디테일)**.

근거 수치 종합:

- **안정**: 방 수 7 (3/3 런 동일), 미매칭 방 0, should_show 앵커 14/14, 이성계
  방·visibility 3/3 일치, 매크로 학습 흐름(건국→임진왜란→중기→후기→사상) 3런 모두 등장
- **흔들림**: 매칭 자카드 평균 0.61, 최소 0.16, 페어당 평균 ~72개 엔티티가 방을
  이동, ~49개의 visibility가 변경, 누락된 할당이 런마다 다름 (37 / 20 / 3)

권고: temp=0인데도 멤버십 자카드 평균 0.61에서 출렁이는 만큼 overlap200 step-3
LLM-only 설계는 같은 입력에서도 디테일이 흔들린다. 학습 흐름 척추 자체는
재현되므로 TOC가 시급한 정도는 아니지만, 방 안 노출 엔티티가 안정해야 하는 UX
(예: 외울 카드 묶음 고정)에는 N>1 majority/anchor 록인 같은 후처리가 필요하다.
온도가 0 초과인 배포라면 더 흔들릴 가능성이 크다.
