- **Level 0 개수 변화 미미 (31 → 30)**: 목표 ≤10에 한참 못 미침. max_cluster_size를 늘려도 `use_lcc=false`로 비연결 컴포넌트들이 각자 별도의 root 클러스터로 남기 때문. size=2 미니 군집은 9개 → 7개로 약간 줄었을 뿐, 구조적으로 안 해결됨.

- **결론**: max_cluster_size=15는 의미 통합 효과는 좋지만 level 0 수 자체는 못 줄임. 다음 실험 3(=20)에서도 같은 한계 예상. level 0 ≤10 목표는 use_lcc=true가 필요해 보임.
